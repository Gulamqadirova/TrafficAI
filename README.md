# TPBI — AI Traffic & Pedestrian Business Intelligence Platform

A complete BI + AI pipeline that detects, tracks and counts **people and cars**
in video, derives traffic/footfall analytics, finds anomalies, forecasts demand,
and serves KPIs, charts, an Excel BI report and a natural-language chatbot.

Built for **Unit 12: Business Intelligence** — *AI-Driven Business Intelligence
Platform for Smart Surveillance and Human Activity Analytics* — and modelled on
the classic YOLO person + vehicle detection / tracking / counting project.

## Runs anywhere (offline)
Object detection prefers **YOLOv8** (`ultralytics`) but transparently falls back
to OpenCV's built-in **HOG** (people) + a **Haar cascade / shape heuristic**
(cars) if YOLO is unavailable — so `pipeline.py` always produces real two-class
detections with no model download. All input data is generated by
`synthetic_data.py` (a real OpenCV traffic clip + a realistic full-day,
4-camera, two-class time-series), so the whole pipeline runs with no live feed.

## Run it
```bash
pip install -r requirements.txt
python pipeline.py
```
Outputs (in `outputs/`): `annotated_traffic.mp4`, five `chart_*.png`,
`Traffic_BI_Report.xlsx`, and `run_summary.json`.

## Module map
| Layer | File | Responsibility |
|-------|------|----------------|
| Config | `config.py` | Classes (person/car), zones, thresholds, paths |
| Ingest | `synthetic_data.py` | Generate traffic clip + 2-class history |
| Perceive | `detection.py` | YOLO/OpenCV multi-class detection (+NMS) |
| Perceive | `tracking.py` | Per-class centroid tracker + line counters |
| Perceive | `video_analytics.py` | Frame loop: detect → track → count → annotate |
| Analyse | `anomaly_detection.py` | Isolation Forest + per-metric z-score |
| Analyse | `predictive_analytics.py` | Ridge car & pedestrian forecasting |
| Present | `bi_dashboard.py` | KPIs, charts, openpyxl Excel report |
| Assist | `chatbot.py` | Natural-language BI assistant |
| Orchestrate | `pipeline.py` | Runs all five stages end-to-end |

Each module also runs standalone (`python <module>.py`).

## Production swap-in
* `MultiClassDetector` → real YOLOv8 weights (uncomment `ultralytics`).
* `synthetic_data` → RTSP/Kafka ingestion + warehouse query.
* `bi_dashboard` → Power BI dataset refresh.
* `TrafficChatbot.ask()` → LLM API with retrieval over the analytics tables.
